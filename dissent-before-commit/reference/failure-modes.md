# Seven ways this fails while the record looks complete

**The one it exists to catch — stale dissent reuse.** The team points at the
dissent discussion from authoring time as proof that concerns were heard, and
proceeds without checking what changed since. The record is real and was honest
when written. Meanwhile there was an incident in the dependency, two customers
asked for a delay, and the engineer who wrote the rollback path left. Nothing in
the old record is false; it is simply no longer about this situation. The
re-canvass is the only defense, and it is the step most likely to be skipped
because the artifact already exists.

**"Heard and considered" laundering.** Dissent recorded, acknowledged warmly, and
neither addressed nor accepted. This is the default outcome of a well-run meeting,
which is why addressed-or-accepted is a hard rule rather than a preference.

**Forced-ranking dodge.** Three co-equal cases produced to avoid saying which is
worst. Reads as thoroughness, functions as a hedge.

**Strawman dissent.** Objections nobody held, easy to dismiss, included so the
section has content. Check whether the named perspective was actually consulted and
whether the objection has a documented basis.

**One-way-door blindness.** An irreversible action proceeding on an acknowledged
objection. Reversibility is classified first precisely because it changes what
counts as sufficient.

**Dissent shopping.** Canvassing until one perspective says "no concerns" and
stopping there.

**Rubber stamping.** Every record across every action reads identically. If the
strongest case does not vary meaningfully between actions, the review has become
paperwork. Compare a few and see.
