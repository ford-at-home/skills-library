# Six ways this produces a log that reads as deliberation

Each of these leaves an artifact that looks like a completed roundtable.

**The one it exists to catch.** One pass produces seven headed sections that all
agree, each restating the proposal's own framing in a different register. It looks
like a panel and reads like a brochure. Symptom: no tension table entries, and
every criterion passes. A run that never kills anything is not filtering. In the
source system, 20 of 72 evaluated proposals received a kill verdict — that
proportion is what a set with teeth looks like.

**Persona capture.** Whichever viewpoint speaks first sets the frame and the rest
justify it. The blind first phase is the only defense; if you shortcut it because
the parallel dispatch is awkward, you have lost the mechanism and kept the
paperwork.

**Criterion softening.** A criterion fails, and the verdict becomes "refine, with
attention to ownership." That is a kill wearing a euphemism, and the proposal will
absorb six months before dying anyway.

**Fabricated grounding.** A persona under pressure to sound evidence-based invents
a comparable city, a grant program, or an adoption statistic. The mandatory
research triggers exist because these are exactly the claims that get invented.

**Tension laundering.** Two personas flatly contradict each other; the synthesis
records "both raised considerations about feasibility." The disagreement was the
product and it has been summarized away. Its close relative is the verdict written
from the impression the run left rather than from the log, which quietly reverses
a finding nobody rereads.

**Politeness convergence.** By challenge round three everyone is conceding
gracefully. This is why the cap is three and why a persona that agrees with
everything gets re-run rather than accepted.
