# How friction scoring goes wrong

**The one it exists to catch.** A message reads fine to its author, because the
author already holds all the context. The reader's cost is invisible from the
sending side. The score makes it visible enough to argue about.

**Symmetric scoring.** Uncertain scorers put everything near 10/20, the total
lands mid-band, and the output says nothing. Commit to specific scores or say you
cannot score that component.

**Flattery.** A 45 described as "looking good" is worse than no score. If the ask
is buried, say the ask is buried.

**Compressing away the position.** The rewrite is shorter, better structured, and
no longer claims anything. Hedges get introduced while trimming, and the sender
ships a message that commits to nothing.

**Losing a constraint.** A date, a name, or a dollar figure disappears in the
compression. The message reads better and is now wrong. This is why the preserved
list exists.

**Compressing what should have been said out loud.** The rubric works on
operational messages. Applied to news that affects someone personally, it
produces a technically excellent message that damages a relationship.

**Rewriting the clean ones.** Every message gets processed because the tool is
available, and the sender loses the ability to tell which drafts actually needed
it.
