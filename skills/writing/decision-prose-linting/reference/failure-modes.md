# How this goes wrong

Each of these produces a document that reads better than the one it replaced.
That is why the corresponding rules in SKILL.md are rules and not preferences.

**Laundering by relabel.** An unsupported claim gets tagged `[assumption]` and
passes. That is legitimate only if the document survives the reader treating it
as untested. If the argument depends on it, it needs evidence, not a tag.

**False precision.** A number is invented to satisfy "metric required". This is
the worst failure available here, because it launders a guess into a fact inside
a document that will be quoted.

**Over-pruning.** Nuance is stripped to satisfy a rule. If the original carries
meaning the rewrite does not, restore it and log the conflict.
