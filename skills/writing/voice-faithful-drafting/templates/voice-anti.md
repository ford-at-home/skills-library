## Vague authority

<!--
Constructions that signal "I read this somewhere" rather than "I know this".
The starter set below is generic; add the ones you actually catch yourself
writing.
-->

- "in today's fast-paced world" -> cut
- "leveraging" -> the actual verb (build, ship, exploit, lean on)
- "in order to" -> "to"
- "utilize" -> "use"
- "industry-standard" -> name the vendor, the version, or the practice
- "best practices" -> name whose practice, and where it came from
